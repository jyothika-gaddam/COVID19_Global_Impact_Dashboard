# COVID-19 Global Impact Dashboard

## Project Overview
This project demonstrates an interactive dashboard for exploring COVID-19 cases, deaths, and vaccination trends using Python.

## Technologies Used
- Python
- Pandas
- Plotly
- Streamlit

## Features
- Interactive country selection
- Daily case analysis
- Cumulative case comparison
- Death trend visualization
- Vaccination progress charts
- Dataset filtering and CSV export

## Dataset
The included dataset contains synthetic demonstration data created for testing and educational purposes. It does not represent actual COVID-19 statistics.

## How to Run
Install the required libraries:

```bash
python -m pip install pandas plotly streamlit
```

Launch the dashboard:

```bash
python -m streamlit run dashboard/app.py
```

## Limitations
The demonstration dataset is small and fictional. Conclusions about real-world pandemic trends require verified public health data.
