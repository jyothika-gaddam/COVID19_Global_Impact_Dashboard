# COVID-19 Global Impact Dashboard

## 1. Project Overview

The COVID-19 Global Impact Dashboard is a data analytics project developed using Python, Pandas, Plotly, and Streamlit. It presents COVID-19 sample data through interactive charts and summary metrics.

## 2. Project Objectives

- Explore COVID-19 case and death trends.
- Compare data across selected countries.
- Display daily new cases and cumulative cases.
- Visualize reported deaths and vaccination figures.
- Provide a downloadable CSV file for further analysis.

## 3. Tools and Technologies

- Python
- Pandas
- Plotly
- Streamlit
- CSV datasets

## 4. Dashboard Features

The dashboard includes country selection, summary metrics, daily case trends, cumulative case trends, death comparisons, vaccination visualizations, a data table, and CSV export.

## 5. Data Description

The current dashboard uses a small synthetic dataset created for demonstration and testing. Its figures are illustrative and do not represent actual COVID-19 statistics.

## 6. Findings and Limitations

The dashboard demonstrates how time-series data can be filtered, summarized, visualized, and exported. Because the current dataset is synthetic and limited, it cannot support conclusions about the actual global impact of COVID-19.

## 7. Future Improvements

- Integrate a verified real-world COVID-19 dataset.
- Add confirmed cases and deaths per million people.
- Include date-range filtering and moving averages.
- Add country-level comparisons using real data.
- Improve data validation and automated reporting.

## 8. Conclusion

This project demonstrates basic data cleaning, exploratory analysis, interactive visualization, and dashboard development. Integrating reliable real-world data would make it more suitable for evidence-based analysis.
